• ❤ 수명이 없어졌어요: 홈 ❤는 이제 함께한 시간. 돌봄을 소홀히 하면 수명 대신 컨디션이 떨어져요
  • 💊 회복 데이터: 연장 데이터가 회복 데이터로 바뀌었어요. 가방에서 쓰면 떨어진 컨디션을 되돌려요
  • 👟 진화 걸음 조건 완화: 성숙기 1,500 · 완전체 4,000 · 궁극체 6,000보
  • 💻 PC를 안 켠 날은 돌봄 멈춤: 디지워커가 꺼져 있던 동안은 배고픔·똥·병이 안 생겨요 (윈도우)
  • ⌨️ 3타 = 1보: 타자로 걸음이 더 잘 쌓여요 (윈도우)
  • 🏆 랭킹 자동 도전 결과 모아 보기: 자동 도전이 끝나면 몇 승 몇 패·점수·보상을 한 번에 보여 줘요

❤ 수명 → 컨디션 하락

  • 수명이 없어져서 디지몬이 흩어지지 않아요. 디지타마로 돌아가기는 예전처럼 완전체부터 직접 골라요
  • 홈 왼쪽 위 ❤ = 알부터 함께한 시간
  • 예전에 수명이 줄던 일은 이제 컨디션을 떨어뜨려요 (쌓여서 최대 −10%)
상황 컨디션
하루 동안 한 번도 안 봄 하루마다 −2%
병을 하루 넘게 둠 하루마다 −3%
자는데 깨워서 훈련·배틀 −1%
일주일 평균 걸음 3,000 미만 자정마다 −1%
  • 회복: 자정마다 +1% · 주간 걸음 목표 달성 +5% · 회복 데이터 = 전부
  • 컨디션을 누르면 "쌓인 하락"이 따로 보여요

💊 회복 데이터

  • 가지고 있던 연장 데이터는 같은 개수의 회복 데이터가 돼요
  • 레이더·만남 아이템, 친구 배틀, 카드 세트 보상에서 드물게 나와요 (친구 배틀은 승 5% · 패 3%)
  • 조그레스 모집의 "수명 2일 넘게" 조건이 없어졌어요

💻 윈도우

  • 디지워커가 꺼져 있던 동안(PC 끔·잠자기·디지워커만 안 켬)은 배고픔·돌봄 실수·똥·병이 멈춰요. 진화 시간은 그대로 흘러요. 창을 트레이에 내려 둔 건 켜져 있는 거라 평소대로예요
  • 걸음 평균(컨디션 3일·걸음 목표 7일)은 PC를 켠 날만으로 계산해요. 주말에 안 켜도 평균이 안 떨어져요
  • 4타 → 3타 = 1보. 지금까지 쌓인 걸음은 그대로예요. 만남 점은 1,500타마다
  • 창을 내렸다 올리면 빈 화면이 되던 것 고침

  • 랭킹 자동 도전이 끝나면 합친 결과 팝업 (멈추기로 끝내도 그때까지)
