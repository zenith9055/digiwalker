  • ✨ 합성 결과 연출: 에픽·전설 카드는 화면 번쩍임 대신 카드 둘레가 빛나요
  • 🔔 새 버전 알림이 더 빨라요: 껐다 켜지 않아도 탭을 바꾸거나 앱으로 돌아오면 바로 알려 줘요

🃏 합성

  • 아래에서 카드를 안 고르면 위 칸에서 자동 합성: 등급(일반·레어·에픽, "모든 카드"를 켜면 전설까지) · 장수(1·3·5·10)
  • 들어갈 재료를 미리 보여 줘요 (카드마다 쓰는 장수, 길게 누르면 정보)
  • 많이 겹친 카드부터 쓰고, 카드마다 한 장은 남겨요
  • 아래 카드 3장을 톡하면 예전처럼 골라서 합성
  • "모든 카드"가 꺼져 있으면(기본) 아래 목록에도 겹친 장수만 보여요. 1장뿐인 카드·덱 카드는 없어진 게 아니라 숨은 거예요 — 켜면 다시 보여요
  • "모든 카드"를 켜면 겹친 장수 → 덱에 없는 카드 → 덱 카드 순으로 써요. 덱 카드가 없어지면 확인 창에서 알려 줘요
  • 합성 촉매를 켜 두면 쓰기 전에 "합성 촉매 확인" 창이 한 번 더 떠요 (남는 개수 표시)
  • 결과는 10연뽑 화면처럼 한꺼번에 보여 줘요
