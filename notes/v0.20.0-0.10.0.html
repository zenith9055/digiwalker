⚔️ 전투가 새로 바뀌었어요 — 꼭 업데이트해 주세요

  • 전투 규칙·카드 수치·훈련 상한을 처음부터 다시 맞췄어요. 친구 배틀은 두 사람 모두 이 버전이어야 해요.
  • 랭킹전: 도전 횟수(10분마다 1번, 5번까지)·자동 도전·도전권 아이템, 연승·연패 매칭
  • 방어·민첩 훈련은 4번 성공하면 끝, 야생은 이겼을 때만 횟수에 쳐요
  • (윈도우) 바탕화면 펫이 창 위에 올라타요 · 정각 한마디 · 본창 크기 조절

바뀐 카드 수치는 내려받기 페이지에서 자세히 볼 수 있어요.

새 기능

  • 랭킹전 도전 횟수: 한 판에 1번 써요. 10분마다 1번씩 차고 5번까지 모여요 (파트너 위 칼 아이콘).
  • 랭킹전 자동 도전: 도전 횟수를 다 쓸 때까지 계속 싸워요. 멈추기 단추가 있고, 도전권까지 쓸지 고를 수 있어요.
  • 랭킹전 도전권 아이템: 쓰면 도전 횟수 +1. 미션 셋 다 깨기·탑 5층마다·시즌 보상·레이더(만남)·야생 승리에서 얻어요.
  • 연승·연패 매칭: 점수가 비슷한 상대 중에서 2연승부터는 나보다 센 상대, 2연패부터는 약한 상대를 만나요.

바뀐 것

  • 방어·민첩 훈련: 4번 성공하면 끝나요 (약 5초). 놓친 만큼 점수가 깎여요. 시작 3·2·1도 빨라졌어요.
  • 야생은 이겼을 때만 그날 만남 횟수로 쳐요. 야생이 나올 확률 75% → 60%.
  • 알림 창이 게임 모양 창으로 바뀌었어요.
  • 랭킹전 시작·계속 도전이 불러오기·저장 중에도 바로 눌려요.
  • 싸우기 전 화면을 한 화면에 들어가게 정리했어요. 덱 문제는 싸우기를 누를 때 창으로 알려 줘요.
  • 랭킹 화면: 자동 도전 아래에 이번 성적·남은 횟수가 보여요.
  • 가방·설정·미션 설명을 짧은 도움말로 바꿨어요.
  • 전투 화면 아래 글 칸이 늘 두 줄 높이라 단추가 오르내리지 않아요.

윈도우

  • 바탕화면 펫이 창 위에 올라타요: 가끔 스스로 올라가고, 끌어서 창 위쪽 끝에 놓아도 올라가요. 창을 옮기면 같이 가고, 창이 닫히면 떨어져요.
  • 정각 한마디: 정각마다 펫이 한마디 해요.
  • 본창 크기: 창 가장자리를 끌면 비율 그대로 70~100%로 줄어들고, 크기를 기억해요.
