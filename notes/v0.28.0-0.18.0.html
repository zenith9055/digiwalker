    • 과식: 밥 먹고 30분 안에 3번 더 주면 돌봄 실수 (3번째엔 확인 창이 먼저 떠요)
    • 똥: 4개째부터 하나 늘 때마다 돌봄 실수
  • ⚠️ 돌봄 실수 전에 미리 알려 줘요: 배고픔·똥으로 실수가 나기 30분 전에 말풍선·알림
  • 💔 돌봄 실수·수면 방해는 유대 −2
  • 😴 자는 중 깨우기 확인: 야생 배틀·친구 배틀도 자는 중이면 먼저 물어봐요
  • 🍖 화면 위 펫·바탕화면 펫은 배 안 고프면 고기를 안 먹어요 (과식은 앱 홈에서만)
  • 🏋️ 훈련 손봄
    • 오른 양을 소수 한 자리까지 쌓아요 — 유년기도 만점과 아닌 게 달라요 (공격 +0.9 / +0.5)
    • 방어·민첩: 디지몬이 커도 어렵지 않게 크기를 맞췄어요. 4번 성공하면 끝, 실패해도 공·허들은 최대 5개
    • 체력: 4초 안에 30번
    • PC판 공격 훈련은 아무 키로 쳐요
  • 🎖️ 훈련 칭호·마을 훈련장은 만점일 때만: 칭호 +30%/+50%, 훈련장 +10/20/30% (만점 1번에 오르는 양 기준)
  • ⏹️ 훈련 그만두기: 뒤로가기(PC는 Esc)를 누르면 묻지 않고 바로 그만둬요 (기록 안 됨)
  • 🔮 진화 예고: 진화 조건을 90% 넘게 채우면 디지몬을 누를 때 가끔 무엇으로 진화할지 말해 줘요
  • 💾 데이터 조각 더 많이
    • 야생 배틀 승리: 레이더 46개 · 만남 35개 (아이템 줍기보다 많아요), 져도 1개
    • 일일 미션 하나 4개 · 셋 다 20개, 오늘의 퍼즐 15개, 로그라이크 탑 층마다 3개
    • 랭킹전 판 보상: 하루 10판까지
  • 🏘️ 마을 건물·장식 값 반으로: 이미 지은 건물·장식은 낸 조각의 절반을 돌려드려요
  • 🏦 데이터 창고 → 데이터 은행: 하루 3/6/10개 대신 전날 모은 조각의 10/20/30%를 줘요 (어울리는 종족이 주민이면 ×1.5), 받은 날 홈에서 알려 줘요
