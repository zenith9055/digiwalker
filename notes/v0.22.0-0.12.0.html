🥚 알·시작

  • 알을 고르면 부화 연출 뒤 바로 유년기 (기다리기·톡으로 앞당기기 없어짐)
  • 알을 넘길 때 미끄러지며 커지고 작아져요
  • 시작 가이드는 알 고르기 전에 나와요 (부화 연출과 겹치지 않게)

👣 걸음

  • 걸음 데이터: 레이더·만남·야생 승리에서 얻어요. 쓰면 오늘 걸음 +1,000 — 진화·미션·레이더 모두 들어가요
  • 며칠 만에 앱을 열어도 걸음이 날짜별로 나뉘어 들어가요
  • 화면 위 펫 말풍선·알림을 72시간치 미리 준비해요 (예전 24시간)
  • (윈도우) 4타 = 1보 (예전 2타)

🧬 진화·돌봄

  • 진화 데이터 아이템 부활 (예전보다 드물게)
  • 쓰다듬기 1번 = 주력 활동 1 (예전 3번)
  • 디지타마로 돌아가기는 완전체부터
  • 기억 리셋 때 돌봄 실수·수면 방해·배틀·야생·친구·승률도 0부터
  • 배틀 화면이 떠 있는 동안엔 진화하지 않아요. 진화할 때가 되면 배틀이 끝난 뒤 저절로 나가서 진화 (랭킹 자동 도전도 멈춤)

⚔️ 배틀·랭킹·탑

  • 방어 기록·기억 보관함을 세대 탭으로 나눴어요. 새 방어 기록 수도 세대별로, 열면 지워져요
  • 이번 주 탑을 완주하면 배틀 탭 탑 칸이 보라 바탕 + 금테 + ✓
  • 탑 보상 층 아이콘이 보물 상자로
  • 시즌 3강·챔피언이면 참가 칭호도 같이 받아요

🃏 카드

  • 합성: 덱에 든 카드는 흐리게 + 넣기 전 확인
  • 전설 카드 합성 스위치 (기본 꺼짐)

🖼️ 화면

  • 화면 글 정리 — 하는 법은 (?) 도움말로
  • 스탯 팝업: 큰 수치 + 이름|값 표 + 훈련 막대
  • 기록은 홈 칩 → 설정 맨 아래 Log
  • 홈 세대·속성·종족을 칸으로, 배경 단추와 한 줄 (겹침 고침)
  • 말풍선 대사가 안 잘려요 (홈은 줄바꿈, 화면 위 펫은 6줄까지)
  • 미션 시트 진행도를 이름 줄 오른쪽으로, 게이지 길이 같게
  • 훈련 탭 (?)에 미니게임 4종 그림과 하는 법
  • 전투 가이드를 짧게
